# سرور ساخت مدل از عکس (اختیاری)

اپ بدون این سرور هم کامل کار می‌کند. این سرور ساخت **واقعی** مش سه‌بعدی از یک عکس را اضافه می‌کند. از مدل آزاد **TripoSR** استفاده می‌کند (کد و وزن‌ها با مجوز MIT).

**محدودیت‌ها، صادقانه:**
- خروجی، مش با رنگ است.
- پشت مدل حدس زده می‌شود.
- اسکلت و انیمیشن ندارد.
- معمولاً از Meshy ضعیف‌تر است.

## روش رایگان: Google Colab (باید هر بار خودتان روشنش کنید)
GPU رایگان Colab تضمینی نیست و بعد از مدتی خاموش می‌شود.

1. در کامپیوتر یا گوشی به colab.research.google.com بروید ← New notebook.
2. از منوی Runtime ← Change runtime type، گزینهٔ **T4 GPU** را انتخاب کنید.
3. فایل‌های `main.py` و `requirements.txt` همین پوشه را آپلود کنید (آیکون پوشه در سمت چپ).
4. دستورهای بخش «Option A» فایل [`README.md`](README.md) را به همان ترتیب در سلول‌ها اجرا کنید.
5. در خروجی، یک آدرس `https://….trycloudflare.com` و یک TOKEN نمایش داده می‌شود.
6. در اپ به بخش **عکس ← سه‌بعدی** ← **سرور پردازش** بروید، آدرس و رمز را وارد کنید و **بررسی اتصال** را بزنید. بار اول دانلود وزن‌ها (حدود ۱٫۷ گیگابایت) چند دقیقه طول می‌کشد.

## حریم خصوصی
عکس فقط وقتی «ساخت» را بزنید، و فقط به همان آدرسی که خودتان وارد کرده‌اید، فرستاده می‌شود. رمز را هرگز در GitHub قرار ندهید.

## هزینه
- خود نرم‌افزار رایگان است.
- Colab رایگان سهمیهٔ محدود دارد.
- اجارهٔ GPU پولی فقط با تصمیم خود شما.
